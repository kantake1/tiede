# DESIGN.md — tiede

このアプリの画面の決まり。見た目のトークンは Airbnb、デスクトップのサイドバーは Airtable の
`topic-filter-rail`、列の区切り方は Cal.com を参考にした。元資料は
[VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) (MIT) の
`design-md/airbnb`・`design-md/airtable`・`design-md/cal`。実装は `src/index.css` 冒頭のトークン。

## 原則

- **白い下地・墨色の文字・色は1つだけ。** アクセント色 Rausch は「主要操作」(追加・更新、＋ボタン) にだけ使う。選択状態・リンク・補助ボタンは墨色で表す。
- **主役は送金額。** 精算カードの金額が画面で最も大きな文字 (Airbnb の rating-display に相当)。
- **影はほぼ使わない。** 面の区切りは 1px の細線と薄灰の面。影は浮いている要素 (＋ボタン) だけ。
- **よく使う操作を表に、設定は奥に。** メンバー・カテゴリ管理はダイアログ、入力フォームはスマホでは全画面シート。

## 色

| トークン | ライト | 用途 |
|---|---|---|
| `--bg` / `--card` | #ffffff | 下地・カード |
| `--surface-soft` | #f7f7f7 | ホバー、送金行、編集中の行 |
| `--surface-strong` | #f2f2f2 | サイドバーの選択行、カテゴリ札 |
| `--text` | #222222 | 本文・見出し・選択状態 (純黒は使わない) |
| `--body` | #3f3f3f | メモなど長めの文 |
| `--muted` / `--muted-soft` | #6a6a6a / #929292 | 補足、プレースホルダー |
| `--border` / `--border-strong` | #dddddd / #c1c1c1 | 細線 / メモの左線 |
| `--accent` / `--accent-active` | #ff385c / #e00b41 | 主要ボタンの通常・押下 |
| `--danger` / `--minus` | #c13515 | 削除・エラー・支払う側の差額。Rausch と区別する |
| `--plus` | #008a05 | 受け取る側の差額、精算不要 (Airbnb に無いアプリ独自色) |
| `--scrim` | 黒 50% | ダイアログ・引き出しの背面 |

ダークモードは Airbnb に無いため、同じ役割を暗色に置き換えた独自定義 (`prefers-color-scheme: dark`)。

## 文字

- 書体: `Inter, -apple-system, system-ui, 'Hiragino Sans', 'Noto Sans JP', …`。Airbnb Cereal の代替として DESIGN.md が挙げる Inter を先頭に置き、無ければシステム書体。
- 見出し h1 22px/600、h2 18px/600。本文 16px、補足 14px。ラベル 14px/500。
- 送金額 22px/700、表形式の数字 (`tabular-nums`)。

## 形と余白

- 角丸: ボタン・入力 8px、カード・送金行 12px、札・トグル 9999px (帯形)。
- 余白: 4px 単位 (4 / 8 / 12 / 16 / 24)。
- タップ領域: 主要ボタン 48px 以上、入力 44px 以上、＋ボタン 56px。

## 部品

| 部品 | 決まり |
|---|---|
| 主要ボタン `button.primary` | Rausch 塗り・白文字・高さ48px。押下で `--accent-active`。無効時は `--surface-strong` の面に `--muted` の文字 (淡いピンクに白文字は読めないため Airbnb から変更) |
| 補助ボタン (レシートを読み取る) | 白地・墨色 1px 枠・墨色文字 |
| テキストボタン `button.ghost` | 墨色文字、ホバーで下線。削除のみ `--danger` |
| 入力 | 白地・細線・角丸8px。フォーカスで枠を墨色 2px 相当に |
| 割り方の切替 | 選択中は墨色塗り・白文字 |
| 品目の対象者トグル | 帯形。ON は墨色塗り・白文字 |
| 精算カード | 送金行は薄灰面・角丸12px、金額 22px/700 |
| メモ | 左に `--border-strong` の線、`--body` 色 |

## アイコン

- [Lucide](https://lucide.dev) (`lucide-react`, ISC ライセンス) の線画アイコンのみ使う。絵文字・記号 (≡ × 🔗 など) や details の既定の三角は使わない。
- サイズ: ボタン内 16px、サイドバー 18px、上部バー 20–22px、＋ボタン 28px。色は文字色を継承する。

## レイアウト

グループ画面は「サイドバー | 支払いを追加 | 精算・一覧」。ブレークポイントは Airbnb に合わせる。

| 幅 | 配置 |
|---|---|
| 1128px 以上 | 3列。サイドバーは格納可 (56px のアイコン列)、状態は端末に保存 |
| 744–1127px | 追加 | 一覧 の2列。サイドバーは左からの引き出し |
| 744px 未満 | 一覧のみ。サイドバーは引き出し、追加は＋ボタンから全画面シート |

**列幅の変更:** 1128px 以上ではサイドバー (180–400px) と入力欄 (340–720px) の境界をドラッグまたは矢印キーで変えられ、端末に保存する。ダブルクリックで既定値 (240px / 420px) に戻す。精算・一覧は 360px を下回らない。744–1127px では入力欄と一覧の境界のみ変更可。

**サイドバー (Airtable `topic-filter-rail` を参考):** 幅240px、白地、右に細線。カテゴリを1行ずつ縦に並べ、選択行は `--surface-strong` の面と太字。各行の右に合計額。カテゴリ一覧の下に、精算済みカテゴリをまとめた折りたたみ式の「アーカイブ」。下部に「URLを共有」「メンバー・カテゴリ」の順。

**上部見出しと格納ボタン (1128px 以上):** 画面上端に高さ52pxの見出し (「tiede / グループ名」、グループ名はクリックで変更) を全幅で置き、サイドバーの状態に関わらず表示する。格納ボタンはラベルなしのアイコンのみで、展開時はサイドバー上端の右、格納時 (幅56px) はボタンだけを中央に置く。1128px 未満は見出しと格納ボタンを出さず、上部バーと引き出しを使う。

**動き:** 格納・展開はサイドバー幅を 0.22 秒で補間し、ラベルはフェードイン。引き出しは横スライドと背景のフェード。ドラッグ中と `prefers-reduced-motion: reduce` では動かさない。
